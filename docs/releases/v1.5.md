# Court Hub v1.5: client-specified figures

Previous release: v1.4 (`0e5282f45ba77290eb9f0b02e56df38bcdfaa93d`).

The homepage numbers section shows only +3,000 active community players and +5 years of experience in padel products. These figures are supplied by the client, not derived from analytics. The arena count and vibration-dampening metric are removed from this section; the rust/structure warranty metric is replaced by experience.

The repeated About arena/dampening counters are replaced with the new community/experience figures; its separate sweetspot statistic is unchanged. The homepage's old arena badge now shows padel-product experience. English and Arabic captions are updated together. Bidirectional number isolation preserves the leading plus sign in Arabic.

New semantic CMS fields replace the retired generic metric fields. Old database rows are retained and ignored by the new source schema. The new fields stay editable in Content Studio. No database writes, image changes, product-status changes, warranty-policy changes or checkout changes are part of v1.5.

Numbers are available accurately in the first server-rendered HTML. The homepage has a responsive two-item layout. v1.4 branded sharing, punctuation, search metadata and hidden-product behavior are preserved.

For rollback, read `/var/backups/courthub/v1.5-backup-path` and restore its previous source and `.next` build, restart only the `courthub` process, then verify the shop/home and save PM2 configuration. No database restoration is needed.
