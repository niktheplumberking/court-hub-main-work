# Court Hub v1.3: approved official product images

The client approved all eight official NOX 2026 model images on 25 October 2026. Every file is a native transparent 1200 × 1200 PNG, copied without re-encoding or AI changes. Source URLs, SHA-256 checksums and previous image URLs are in `v1.3-product-images.json`. These are manufacturer reference photos, including the product marked Good; condition labels are unchanged.

## Release

Run the release-only CLI from the production checkout with its existing protected environment. It must never be exposed through a public application route. The CLI validates the expected project, exact product title/slug, original image array and approved file checksums. It uploads unique storage objects with no overwrite and verifies their bytes before changing only the corresponding image array entries. Prices, stock, status, descriptions and condition are not patched.

```sh
node scripts/release-product-images.mjs --check /protected/backup/images-v1.3.json
node scripts/release-product-images.mjs --apply /protected/backup/images-v1.3.json
```

`--apply` first creates a new protected backup file and refuses to replace an existing backup. Conditional updates avoid overwriting concurrently changed images. If an update fails, the CLI attempts to restore all image arrays it changed, including any update whose response was uncertain. Existing and newly uploaded storage objects are retained.

Rebuild the prepared production release after applying the image changes so prerendered pages contain the new URLs. Verify all eight live images, English/Arabic product pages and the existing Good badge. Keep the prior source, build and environment in the protected production backup.

## Rollback

Read `/var/backups/courthub/v1.3-backup-path` for the canonical protected backup directory. Use the v1.3 checkout to restore its saved catalogue image arrays **before** reverting source/build:

```sh
node scripts/release-product-images.mjs --restore /protected/backup/images-v1.3.json
```

The restore command changes only images and refuses to overwrite any newer image edit. Then restore the saved v1.2 build and source commit, restart only the `courthub` PM2 process, verify the shop and save PM2 configuration. A source-only rollback does not revert catalogue data. Never delete storage objects as part of rollback.
